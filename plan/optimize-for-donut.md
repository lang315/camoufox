# Camoufox / Donut Optimization Plan

## Executive summary

Camoufox 146.0.1 reads spoofing values from a single `CAMOU_CONFIG` JSON blob through the typed getters in `additions/camoucfg/MaskConfig.hpp`. Two producers feed that contract: **donutbrowser** (Rust launcher) and **goapi** (Go driver) — both must emit exactly the keys the patched binary reads, and both must override the binary's bundled `settings/camoufox.cfg` defaults via Firefox user-prefs. The highest-leverage wins are: (1) **goapi navigation is silently broken** — it ships `Page.GoBack/GoForward` yet both emits a history-clamping `window.history.length` (F1) and never re-enables the session history that `camoufox.cfg` zeroes out (F2); donut already fixed both. (2) **goapi has an open proxy leak** — QUIC/HTTP3 is never disabled when a proxy is set (F5), letting UDP traffic bypass the HTTP/SOCKS proxy. (3) **Both producers emit dead keys** — donut ships `canvas:aa*`, `navigator.appName/appCodeName/product/doNotTrack/maxTouchPoints`, and `webGl2Enabled`, none of which 146 reads — pure payload bloat and false spoof signals. (4) **Both leave fingerprint surfaces partially spoofed** — donut omits `battery:level` and `canvas:seed`; goapi spoofs only the WebGL vendor/renderer strings and the geo timezone, leaving `getParameter`/`getShaderPrecisionFormat` and `navigator.language` at host values — classic CreepJS-class internal inconsistencies.

## Target: camoucfg-contract (MaskConfig.hpp consumer hardening)

### 1. MC-3 — `GetString` performs no type check before `get<std::string>()` *(low / low risk)*
- **Repo:** camoufox
- **File:** `additions/camoucfg/MaskConfig.hpp:94-98`
- **Now:** `GetString` does `if (!HasKey(key, data)) return std::nullopt; return data[key].get<std::string>();` with no `is_string()` guard. Every sibling getter validates the JSON type and returns `nullopt` with a `printf_stderr` on mismatch (`GetUintImpl:123 is_number_unsigned()`, `GetInt32:140 is_number_integer()`, `GetDouble:148-151`, `GetBool:158-159`). Many donut keys flow through `GetString` (userAgent/appVersion/platform/oscpu, timezone, locale:*, headers.*, webGl:renderer/vendor, webrtc:*) — all serialized as strings today, so no live failure, but a single non-string value (e.g. a future numeric timezone offset, a malformed preset) throws an uncaught `nlohmann type_error.302` instead of degrading to native.
- **Change:** Add the mirroring guard before the get: `if (!data[key].is_string()) { printf_stderr("ERROR: Value for key '%s' is not a string\n", key.c_str()); return std::nullopt; }`. Callers already treat `nullopt` as "use native".
- **Risk:** low.

### 2. MC-4 — `GetStringList` does not validate array shape or element type *(low / low risk)*
- **Repo:** camoufox
- **File:** `additions/camoucfg/MaskConfig.hpp:100-108`
- **Now:** `for (const auto& item : data[key]) { result.push_back(item.get<std::string>()); }` with no `is_array()` guard and no per-item `is_string()` check. Consumes donut's `fonts` (`font-hijacker.patch:18`, emitted as a JSON array of strings via `config.rs:400,402`) and `webGl[2]:supportedExtensions` (`webgl-spoofing.patch:617-618,637-638`). A non-string element throws `nlohmann type_error` rather than failing soft to native fonts/extensions. **Verifier note:** iterating a JSON primitive yields one element without throwing, so the precise failure mode is a non-string *element*, which the guard below covers.
- **Change:** Guard container shape and element types: `if (!data[key].is_array()) { printf_stderr(...); return {}; }`, and inside the loop `if (item.is_string()) result.push_back(item.get<std::string>());` (skip non-strings). **Verifier correction:** `supportedExtensions` is *not* emitted by donut today (only typed in this repo and consumed by camoufox patches); `fonts` is the live donut-emitted payload this guards.
- **Risk:** low.
