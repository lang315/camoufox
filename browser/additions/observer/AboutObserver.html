Tracking observer

The counts are drain windows of about 500 ms, not read counts: read them as touched or not touched.

Silence is not safety. The observer is blind to:

  • Engine-cached surfaces — timezone, locale / Intl.
  • Un-spoofed surfaces — navigator.vendor, plugins / mimeTypes, deviceMemory, userAgentData (Client Hints), mediaDevices.enumerateDevices, getBattery, navigator.connection. These return the real device value.
  • Worker / OffscreenCanvas reads that happen off the main thread with no owning document.
